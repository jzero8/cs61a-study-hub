# CS 61A Study Hub

A single-page study guide for UC Berkeley CS 61A (Fall 2026):

- **Content** — mind map of the six course units plus the four projects, with sub-points, examples, common mistakes and self-check questions for every topic.
- **Exams** — grading breakdown, quiz rules and schedule, scope and preparation for each midterm and the final.
- **Practice** — 55 practice questions (WWPD, coding, concept, SQL) with hints, answers and explanations, filterable by unit and exam.

## Structure

```
index.html   # the whole site (HTML + CSS + JS, no build step)
fonts/       # self-hosted Latin fonts (Bricolage Grotesque, JetBrains Mono, OFL)
```

No external requests: fonts are self-hosted and Chinese text uses system fonts, so the page loads in mainland China without a VPN.
